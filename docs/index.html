Connect Between Us

To create a private multiplayer world you need a Supabase project URL, a publishable key, deployed game-api Edge Function, the game SQL migration, and anonymous sign-in enabled.

Never enter a service_role or sb_secret key. This saves the public key only in this browser. To make online play automatic for your friend, also add the same public settings to docs/config.js on GitHub.
